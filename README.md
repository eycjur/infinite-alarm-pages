- 公開URL: https://eycjur.github.io/infinite-alarm-pages/ （英語版は [/en/](https://eycjur.github.io/infinite-alarm-pages/en/)）
- 不具合報告・機能要望はこのリポジトリの [Issues](https://github.com/eycjur/infinite-alarm-pages/issues) へ（アプリ本体のリポジトリはprivateのため、こちらが公開の問い合わせ窓口です）
- ページを編集する場合は、日本語版（ルート直下）と英語版（`en/`）の両方を更新してください
